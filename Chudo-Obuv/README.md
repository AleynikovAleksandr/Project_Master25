# Чудо Обувь

Приложение для заказа обуви в сети магазинов «Чудо Обувь». Клиент выбирает модели и размеры из каталога и оформляет заказ, менеджер и администратор работают со списком заказов.

Сделано на Python: окно приложения — pywebview, страницы — Flask, база данных — MySQL.

## Что умеет каждая роль

| Роль | Что доступно |
|---|---|
| Неавторизованный пользователь | просмотр каталога (без поиска, фильтра и сортировки) |
| Авторизованный пользователь | каталог с поиском, фильтром и сортировкой, карточка товара, оформление заказа |
| Менеджер | всё, что у пользователя, + список заказов, состав заказа, новый заказ на клиента, удаление заказа |
| Администратор | всё, что у менеджера, + редактирование заказа: клиент, дата, количество в позициях, добавление и удаление позиций (остатки на складе пересчитываются) |

Права всех ролей описаны в одном месте — в `apl/access.py`. Там же проверка, которую используют все страницы.

Вход только по логину, пароль не нужен. Логины есть в `database/import/Users_import.xlsx`, например:

| Роль | Логин |
|---|---|
| Администратор | `isivanov` |
| Менеджер | `papetrov` |
| Авторизованный пользователь | `asidorova` |

## Каталог

- В карточке товара: фото, категория, производство и наименование, состав, цена со скидкой и количество («много», если пар больше пяти, иначе «мало»).
- Если фото нет, показывается заглушка `picture.png`.
- Товары, которых осталось 3 пары и меньше (по всем размерам), подсвечиваются цветом `#ff8080`.
- Скидка 25% даётся на товары, которых не было в заказах в прошлом календарном месяце.
- Поиск по наименованию и описанию, фильтр по категории и сортировка по цене работают сразу при вводе и действуют вместе.

## Сообщения

Ошибки, предупреждения и информация показываются в окнах с заголовком и значком. Перед удалением, подтверждением и отменой заказа приложение спрашивает подтверждение.

## Структура

```
app.py              запуск окна, вход и выход
core/
  render.py         сборка страниц из шаблонов, формат цены
  static_server.py  локальный сервер для страниц и файлов static/
db.py               подключение к БД и общие запросы
config.py           данные подключения к MySQL
apl/
  access.py         права ролей — одна точка проверки
  catalog.py        каталог и карточка товара
  cart.py           формирование и оформление заказа
  orders.py         список заказов, состав, удаление и редактирование
templates/          страницы
static/             стили (css/), скрипты, логотип, иконка, фото товаров
database/
  schema.sql        скрипт БД: создание таблиц
  import_data.py    загрузка данных из Excel-файлов в таблицы
  import/           файлы заказчика
docs/
  Untitled.pdf      ER-диаграмма (dbdiagram.io)
```

## Запуск

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откроется окно приложения «Чудо Обувь».

Подключение к MySQL и имя базы задаются в `config.py` (`DB_NAME`).

При запуске приложение само создаёт базу `DB_NAME`, если её нет. Если в базе нет таблиц, оно создаёт их по `database/schema.sql` и загружает данные из Excel-файлов. Если таблицы уже есть, данные не трогаются.

`python database/import_data.py` пересоздаёт таблицы и загружает данные из Excel заново. Заказы, оформленные в приложении, при этом пропадут.
